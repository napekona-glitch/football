# Football Club Website

A simple HTML-based website inspired by bloomsburyfootball.com, featuring a modern design with football programmes and community focus.

## Features

- **Hero Section**: Eye-catching header with call-to-action buttons
- **Mission Section**: Organization's mission and values
- **Features Grid**: Three key benefits (Safe Place, Community, Tools to Progress)
- **Statistics Section**: Impact numbers displayed prominently
- **Testimonial**: Player quote showcasing impact
- **Programmes Section**: Six different football programmes with descriptions
- **Financial Support**: Information about accessibility and discounts
- **Responsive Navigation**: Sticky header with navigation links
- **Footer**: Organized links and contact information

## How to Use

1. Open `index.html` in any web browser to view the website
2. No build process or dependencies required
3. Fully responsive design works on mobile, tablet, and desktop

## Customization

- Edit the HTML content to update text, links, and sections
- Modify the CSS in the `<style>` tag to change colors, fonts, and layout
- Replace placeholder links with actual URLs
- Add images by including `<img>` tags in appropriate sections

## Color Scheme

- Primary: Dark Blue (#1a1a2e)
- Accent: Green (#4ade80)
- Background: Light Gray (#f8fafc)
- Text: Dark Gray (#333)

## Browser Compatibility

Works on all modern browsers including Chrome, Firefox, Safari, and Edge.
